JEV STORY

Hard filters, then a typed read

Math first. Jev only sees names that already passed the numbers, and only as a facts-only state string.

Live · illustrative tape Separate from Saturday’s freeze.
Does not write the research book.

This tab is always on the site. It is not a screener rank, not Form 4 insights, and not mixed into desk.json. The weekly publish can stay untouched.

  1. Phase 1 Numerical pre-filter Trailing max drawdown, beta, debt-to-equity, and operating margin are hard gates. Fail any one and the name never reaches Jev. This step is arithmetic, not a model.
  2. Phase 2 Facts-only state Survivors are turned into a short equity profile: listed metrics plus catalyst text. No “buy”, “cheap”, or “asymmetric” labels. Jev is state-sensitive; editorial wording would steer the answer.
  3. Phase 3 Typed questions, then a rule Choice / Score / Noul come back as numbers software can branch on. Low confidence, or a Noul in the middle, is a dry run — not a pass. The model does not value the asset and does not write prose.

Limits. Jev cannot do fundamental valuation. A high Score is not a 100% annual-return forecast. Ambiguous filings should fail the confidence gate rather than be forced into a bucket.
